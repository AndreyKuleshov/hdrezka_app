# Fox TV — приложение для Android TV

Приложение открывает сайт [serialy-fox-hdrezka.net](https://serialy-fox-hdrezka.net/) на Android TV во встроенном браузере (WebView), удобном для управления пультом: экранный курсор, полноэкранное видео, медиакнопки.

## Возможности

- Навигация стрелками по элементам страницы: фильтрам, карточкам, кнопкам, сериям. Выбранный элемент подсвечивается оранжевой рамкой, OK нажимает его (открывает выпадающие списки, поле поиска с клавиатурой и т.п.).
- Поддержка air mouse (пульта-указки): курсор работает как обычная мышь.
- Запасной режим «курсор стрелками» для пультов без гироскопа: стрелки двигают экранный курсор, у края экрана прокручивается элемент под курсором.
- Панель разделов: боковое меню с разделами сайта (жанры, категории). Пункты берутся из меню самого сайта, поэтому список обновляется вместе с сайтом.
- Переключение серий: на странице сериала внизу появляется плашка «◀ Предыдущая · Сезон 1 · Серия 2 из 6 · Следующая ▶», в конце сезона переход идёт на соседний сезон.
- Полноэкранный режим для видео из плеера сайта, медиакнопки пульта.
- Сохраняются cookies (вход в аккаунт) и последняя открытая страница.
- Блокируются рекламные всплывающие окна и переходы на внешние схемы (`intent://`, `market://`).

## Управление с пульта

| Кнопка | Действие |
|---|---|
| Стрелки | Перейти к соседнему элементу страницы (в режиме курсора — двигать курсор) |
| OK | Нажать выбранный элемент (в режиме курсора — нажать в точке курсора) |
| Долгое нажатие OK | Открыть панель разделов |
| Menu | Открыть/закрыть панель разделов (на некоторых ТВ эту кнопку забирает система — тогда используйте долгое OK) |
| Назад | Закрыть панель, выйти из полноэкранного режима, вернуться на предыдущую страницу, выйти из приложения (двойное нажатие) |
| ⏭ / ⏮, CH+ / CH− | Следующая / предыдущая серия (на странице сериала; на других страницах CH+/CH− прокручивают страницу) |
| Play/Pause, ⏩, ⏪ | Управление видео |
| Air mouse | Курсор мыши, клик — как на компьютере |

В панели разделов, кроме разделов сайта, есть «Главная», переключение серий, «Назад», «Обновить страницу» и переключение режима «выбор элементов ↔ курсор стрелками».

> Медиакнопки работают, только если видео встроено прямо в страницу. Если плеер загружен с другого сайта (в iframe), управляйте им курсором или стрелками.

## Установка на телевизор

Готовый APK собирается автоматически через GitHub Actions:

- **Релизы** — на странице [Releases](https://github.com/AndreyKuleshov/hdrezka_app/releases) скачайте `FoxTV-vX.Y.apk` из последнего релиза.
- **Свежая сборка из `main`** — вкладка [Actions](https://github.com/AndreyKuleshov/hdrezka_app/actions/workflows/build.yml) → последний успешный запуск → артефакт `FoxTV-apk` (нужен вход в GitHub, внутри zip-архив с APK).

Можно также собрать APK самостоятельно (см. [Сборка](#сборка)).

### Вариант 1. Через USB-флешку

1. Скопируйте APK (`FoxTV-*.apk` из релиза или `app-release.apk` из своей сборки) на флешку и вставьте её в телевизор.
2. Разрешите установку из неизвестных источников: **Настройки → Приложения → Безопасность и ограничения → Неизвестные источники**, затем включите разрешение для файлового менеджера, которым будете открывать APK. Названия пунктов зависят от модели телевизора.
3. Откройте APK в файловом менеджере (например, *X-plore* или *File Commander*) и нажмите «Установить».

### Вариант 2. По сети через adb

1. На телевизоре включите режим разработчика: **Настройки → Об устройстве → Сборка** — нажмите 7 раз.
2. Включите **Настройки → Для разработчиков → Отладка по сети (ADB)**. Узнайте IP-адрес телевизора в настройках сети.
3. На компьютере (в той же сети) выполните:

   ```bash
   adb connect <IP_телевизора>
   adb install -r FoxTV-v1.0.apk   # путь к скачанному или собранному APK
   ```

   При первом подключении подтвердите запрос на телевизоре.

После установки приложение **Fox TV** появится в списке приложений на главном экране.

## Сборка

### GitHub Actions

Workflow [`.github/workflows/build.yml`](.github/workflows/build.yml) собирает APK при каждом пуше в `main`, в pull request'ах и при ручном запуске (**Actions → Build APK → Run workflow**).

Чтобы выпустить релиз, создайте тег версии — APK автоматически прикрепится к новому релизу:

```bash
git tag v1.0
git push origin v1.0
```

### Требования

- JDK 17
- Android SDK: `platforms;android-35` (нужная версия build-tools Gradle докачает сам)
- Интернет для первой сборки (Gradle скачает зависимости)

### Через Android Studio

Откройте папку проекта в Android Studio и выберите **Build → Build APK(s)**.

### Из командной строки (macOS)

```bash
# 1. JDK и Android command-line tools
brew install openjdk@17
brew install --cask android-commandlinetools   # или скачайте с developer.android.com

# 2. Компоненты SDK
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
sdkmanager --licenses
sdkmanager "platform-tools" "platforms;android-35"

# 3. Путь к SDK для проекта
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties

# 4. Сборка
./gradlew assembleRelease
```

Готовый файл: `app/build/outputs/apk/release/app-release.apk`.

### Подпись

Если заданы переменные окружения `SIGNING_STORE_FILE`, `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS` и `SIGNING_KEY_PASSWORD`, release подписывается этим ключом. Иначе используется debug-ключ, который у каждой машины свой: APK, собранные на разных машинах, не ставятся поверх друг друга (нужно удалить старую версию, при этом сбросится вход на сайт).

В GitHub Actions ключ берётся из секретов репозитория: `SIGNING_KEYSTORE_BASE64` (keystore в base64), `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`.

## Настройка

Адрес сайта задаётся в `app/build.gradle.kts`:

```kotlin
buildConfigField("String", "START_URL", "\"https://serialy-fox-hdrezka.net/\"")
```

Если сайт переехал на другой домен — поменяйте адрес и пересоберите APK. Приложение открывает последнюю просмотренную страницу, поэтому после обновления очистите его данные: **Настройки → Приложения → Fox TV → Очистить данные**.
