# История просмотра и отложенные сериалы

Дата: 2026-10-12

## Задача

Приложение не помнит ничего: вечером приходится вспоминать, на какой серии остановился,
а отметить сериал «посмотрю потом» негде. Нужны три вещи:

1. позиция внутри серии и список просмотренных серий;
2. свой экран «Continue watching» / «Saved» с обложками;
3. отметки просмотренного прямо в каталоге сайта.

## Решения (согласованы)

| Развилка | Выбор |
|---|---|
| Хранилище | `SharedPreferences` + JSON, без новых зависимостей |
| Где списки | Свой нативный экран с карточками поверх WebView |
| Как откладывать | Кнопка «★ Saved» на странице сериала (долгое OK остаётся за панелью разделов) |
| Возврат к серии | Сразу с сохранённой позиции, с короткой надписью |
| Обложки | Свой загрузчик (`HttpURLConnection` + кэш), без Glide/Coil |
| Запуск приложения | Свой экран, если есть что продолжить; иначе сайт как раньше |
| Каталог сайта | Полоска прогресса на карточках, галочка у просмотренных серий |

## Данные

`SharedPreferences("library")`, два JSON-массива. История ведётся **по сериалу**, иначе
список превращается в перечисление сотен серий.

```json
{ "u": "https://…/16101-posledovateli-2013",
  "t": "Последователи",
  "p": "https://…/poster.jpg",
  "ep": { "s": "1", "e": "2", "url": "https://…/2-serija", "pos": 862, "dur": 2733 },
  "seen": ["1:1", "1:2"],
  "at": 1760000000000 }
```

Избранное — массив `{u, t, p, at}`.

- Канонический адрес сериала — первые три сегмента пути (`/serial/uzhasy/16101-…`).
- Серия считается просмотренной при `pos > 0.9 * dur` или по событию конца серии.
- Позиция пишется раз в ~10 с из опроса плеера, плюс при паузе, выходе из фуллскрина и уходе в фон.
- Лимиты: 50 сериалов в истории, 100 в избранном; вытесняются самые старые по `at`.

## Компоненты

- `WatchStore.kt` — модель и доступ к `SharedPreferences`: история, избранное, просмотренные серии.
- `PosterCache.kt` — загрузка обложек в фоне, кэш в памяти (`LruCache`) и в `filesDir`.
- `LibraryScreen.kt` — экран с двумя горизонтальными рядами карточек, навигация пультом.
- `FoxBridge.kt` — `@JavascriptInterface`: состояние избранного, переключение, карта просмотренного.
- Правки: `MainActivity` (запуск, пункты панели, мост, открытие серии с позиции),
  `PlayerController` (постер и канонический адрес в `state()`, сохранение позиции, возобновление).

## Потоки

**Просмотр.** Плеер опрашивается раз в 500 мс. Раз в 10 с текущая позиция уходит в `WatchStore`
вместе с названием, постером и номером серии. На 90% длительности серия помечается просмотренной.

**Возобновление.** При запуске серии, если для неё сохранена позиция, после старта выполняется
`seekTo` и на пару секунд показывается «Continue from 14:22».

**Каталог.** Внедряемый скрипт запрашивает у моста карту просмотренного и рисует поверх карточек
полоску прогресса, а в списке серий — галочку.

## Ошибки и края

- Нет сети или постер не загрузился — карточка показывает название на сплошной плашке.
- Сайт сменил вёрстку — бейджи не рисуются, остальное работает: история пишется от плеера.
- `SharedPreferences` повреждены или пусты — приложение стартует с сайта, как раньше.
- Серия без длительности (реклама, незагруженный плеер) — позиция не сохраняется.

## Проверка

Тестов в проекте нет, проверка — на эмуляторе: запуск серии, выход на середине, перезапуск
приложения, возврат через «Continue watching», отметка в каталоге, кнопка «Saved».
